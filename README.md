# 🎵 AutumnPants · Music

> music.qijunhao.com — AutumnPants 的音乐世界

## 板块

| 板块 | 文件 | 内容 |
|------|------|------|
| **听** | `听-板块.html` | Apple Music 数据档案 — 艺人星系、五星珍藏、评分分布、年度趋势 |
| **赏** | `赏-板块（演唱会）.html` | 演唱会记忆 — 陈奕迅、薛之谦、五月天、邓紫棋、陶喆 |
| **演** | `演-板块/dist/舞台时光.html` | 舞台时光 — Vite + React 构建的演出记录（GSAP 动画 + OGL 3D） |
| **创** | `创-板块.html` | 创作空间 — 词曲灵感、作品展示 |
| **首页** | `音乐首页.html` | 四板块入口导航 |

## 技术栈

- 静态 HTML + CSS + JavaScript
- 演-板块：Vite + React + GSAP + OGL (3D)
- 三语言切换（简体中文 / 繁體中文 / English）
- 浅色/深色主题切换

## 本地开发

```bash
# 演-板块（React 应用）
cd 演-板块
npm install
npm run dev
```

## 部署

GitHub Pages + CNAME 自定义域名。推送 `main` 分支自动部署。
